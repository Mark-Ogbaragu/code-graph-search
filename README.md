# code-graph-search
Graph-based code analysis of code structure - shows discrete math applied to Software Engineering.
## What it does
- Parses Python code into Abstract Syntax Tree (AST)
- Builds a directed graph of functions using NetworkX
- Counts functions and their relationships
## Why this matters for AI4SE
Software is a graph. Understanding code as a graph is key for AI tools that search and analyze large codebases.
## Tech
- Python ast, networkx
- Discrete Structures: graphs, DAGs
## Run
pip install networkx
python main.py
